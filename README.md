# Data Structures and Algorithms / Estruturas de Dados e Algoritmos 

This repository contains a collection of C exercises developed during classes. It is organized by topic and includes examples of arrays, linked lists, stacks, queues, trees, hash tables, recursion, sorting, strings, and structs.

Este repositório contém uma coleção de exercícios e implementações em C feitas durante as aulas. Está organizado por tópico e inclui exemplos para vetores, listas ligadas, pilhas, filas, árvores, tabelas hash, recursão, ordenação, strings e structs.

## Structure / Estrutura

- `ADT/` - Abstract Data Types /  Tipos Abstratos de Dados (TAD)
- `binary-tree/` - Merkle tree / árvore de Merkle
- `file/` - File-handling exercises / Exercícios de manipulação de arquivos
- `hash-table/` - Hash table implementation / Implementação de tabela hash
- `linked-list/` - Singly and doubly linked list exercises / Exercícios com listas ligadas simples e duplamente encadeadas
- `matrix/` - Matrix operations exercises / exercícios com matrizes 
- `merge-sort/` - Merge sort examples / Exemplos de merge sort
- `queue/` - Queue implementations / Implementações de fila
- `recursion/` - Recursive problem exercises / Exercícios de problemas recursivos
- `stack/` - Stack implementations / Implementações de pilha
- `strings/` - String handling exercises / Exercícios com strings
- `structs/` - Struct usage and record manipulation / Uso de structs e manipulação de registros
